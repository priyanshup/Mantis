# Personas

1. **Reuse first.** Check `mantis/knowledge/personas.md`. Link the existing entry; don't rewrite it.
2. **New persona card:** role, organisation (e.g. distributor), where and when they work, goal, main pain, today's workaround, digital comfort, devices. One line each.
3. **Evidence level.** Mark it **assumed** (team belief, no research) or **interviewed** (with the interview sources). Never present an assumed persona as researched.
4. **One name per persona.** When sources use different labels ("store assistant manager / IT person", "inventory manager"), list them as aliases in the register and use the register's name in every output.
5. **Primary and secondary.** One primary persona per feature. Others (approvers, admins) are secondary and get one line.
6. Add new personas to the register in the same change, with sources.

Method: persona types (proto, qualitative, statistical), Nielsen Norman Group (https://www.nngroup.com/articles/persona-types/).
