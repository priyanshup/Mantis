# Plain writing

1. **Point first.** The first line of the page and of each section gives the answer or decision.
2. **Say it once.** Each fact lives in one section. Elsewhere, refer to it. Delete recaps, "key takeaways" and repeated status. There is no word limit: cut repetition, not substance.
3. **Short sentences.** Split any sentence over 25 words. One idea per bullet.
4. **Plain words.** Write "buy" not "purchase", "help" not "assist", "use" not "leverage". Spell out acronyms or link the glossary.
5. **Active voice and named people.** "Sam sends the list", not "the list will be shared".
6. **Show the shape.** Comparisons go in a table, sequences in numbered steps, flows in a diagram. Don't describe a table in prose.
7. **Read it as an outsider.** Would an engineer new to the team understand it without asking? Remove anything they would skip.
8. Run the `humanizer` skill last, and check every citation survived.

Method: GOV.UK clear language (https://guidance.publishing.service.gov.uk/writing-to-gov-uk-standards/writing-guidelines/clear-language/). Mantis rules: docs/rules/OUTPUTS_GUIDE.md.
