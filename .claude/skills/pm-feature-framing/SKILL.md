# Feature framing

Do this before any feature page, epic or brief. The output feeds `mantis/TEMPLATES/brief.md`.

1. **Outcome.** Name the one business or customer result this feature moves. If you can't, stop and ask.
2. **Opportunity.** Name the customer need or pain behind it, with the source document. A feature with no cited pain is an idea, not a requirement: say so.
3. **Alternatives.** List one or two other ways to reach the same outcome, including doing nothing and using a spreadsheet. Say why this one.
4. **Scope.** Set the appetite (how much it is worth), then split jobs into MVP, Later and Out (no-gos). Name the rabbit holes: details that could blow up the effort.
5. **Prioritise with RICE:** Reach (people per period), Impact (0.25, 0.5, 1, 2, 3), Confidence (%), Effort (person-months). Score = R × I × C / E. State the scale. Where sources lack a value, propose one, label it Proposed, and ask the owner.
6. **Dependencies.** Check the map and feature cards: what must exist first?

Methods: opportunity solution tree, Teresa Torres (https://www.producttalk.org/opportunity-solution-trees/). Shape Up pitch: problem, appetite, solution, rabbit holes, no-gos (https://basecamp.com/shapeup/1.5-chapter-06). RICE, Intercom (https://www.intercom.com/blog/rice-simple-prioritization-for-product-managers/).
